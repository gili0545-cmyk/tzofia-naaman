# הדף של צופיה נעמן

הדף החי: https://tzofia-naaman.vercel.app

## איך עורכים את הדף
1. פותחים את התוכנה של Claude במחשב, ועוברים ללשונית **Code**.
2. בפעם הראשונה בלבד, כותבים ל־Claude:
   "תוריד לי את הכספת gili0545-cmyk/tzofia-naaman מגיטהאב לתיקייה במחשב, ותפתח אותה."
3. מהפעם השנייה: בוחרים את התיקייה tzofia-naaman וכותבים מה רוצים לשנות.

## דוגמאות למה אפשר לבקש
- "תחליף את המשפט מתחת לכותרת הראשית ל…"
- "תוסיף שאלה לשאלות הנפוצות: … והתשובה: …"
- "תחליף את התמונה למעלה בתמונה הזו" (ולצרף את התמונה)
- "תראה לי איך זה נראה בטלפון"

בסוף כותבים: **"תעלה לאוויר"**. אחרי דקה הדף מתעדכן.

אם משהו השתבש, כותבים: "תחזיר את הדף לגרסה הקודמת".
